Pixel Knight
============

A small platformer game built with Pygame Zero.

Genre: Platformer
The knight walks and jumps across platforms, collects coins, avoids/stomps
two kinds of enemies (a ground-patrolling Slime and a flying Bat) and wins
by collecting every coin and reaching the flag.

Every time you start a new game, the 3 floating platforms (and the coins
sitting on them) are placed at a new random spot and height. Each platform
is always generated fully above solid ground and low enough to be reached
with a single straight jump, so every layout is guaranteed to be completable.


LIBRARIES USED
--------------
- Pygame Zero (pgzero)  -- windowing, game loop, Actor sprites, keyboard,
  sound and music playback.
- math                  -- standard library, used for the bat's flight
  wave motion.
- random                -- standard library, used for enemy idle/patrol
  timing variation.
- Rect (imported directly from Pygame, as explicitly permitted) -- used
  for collision boxes and menu button hitboxes.

No other libraries are imported or required by the game itself.

The images, sound effects and music were generated by a small offline
helper script (tools/generate_assets.py) that only uses the Python
standard library (struct, zlib, wave, math, random, os). That script is
a one-off art/audio tool, not part of the game, and does not need to be
run again unless you want to regenerate the assets.


HOW TO RUN THE GAME
--------------------
1. Install Python 3 (3.12 recommended; pgzero currently requires a
   Python version that Pygame has published wheels for).

2. Install Pygame Zero:

       pip install pgzero

3. From this project folder, run the game with the pgzrun launcher:

       pgzrun main.py

   (If the "pgzrun" command is not on your PATH, you can instead run:
       python -m pgzero main.py   )

The images/, sounds/ and music/ folders already contain the generated
assets, so the game can be run immediately without any extra setup.


CONTROLS
--------
- Left / Right arrows or A / D  : move
- Space / Up / W                : jump
- Escape                        : quit the current level and return to the menu
- Mouse click                   : press menu buttons

Menu buttons:
- Start Game                : begins the level
- Sound: On/Off              : toggles music and sound effects
- Exit                       : closes the game

Jump on top of a Slime or a Bat to defeat it (it respawns after a few
seconds). Touching an enemy from the side costs one heart. Collect all
3 coins, then reach the flag to win. Falling into the pit or losing all
hearts ends the game.

tools/generate_assets.py   - offline helper that generated the assets
